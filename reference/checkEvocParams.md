# Check EVoC params

Checkmate extension for the output of
[`params_evoc()`](https://gregorlueg.github.io/manifoldsR/reference/params_evoc.md).

## Usage

``` r
checkEvocParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
