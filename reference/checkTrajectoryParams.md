# Check trajectory params

Checkmate extension for the output of
[`params_trajectory()`](https://gregorlueg.github.io/manifoldsR/reference/params_trajectory.md).

## Usage

``` r
checkTrajectoryParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
