# Check swiss roll params

Checkmate extension for the output of
[`params_swiss_roll()`](https://gregorlueg.github.io/manifoldsR/reference/params_swiss_roll.md).

## Usage

``` r
checkSwissRollParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
