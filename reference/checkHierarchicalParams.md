# Check hierarchical cluster params

Checkmate extension for the output of
[`params_hierarchical()`](https://gregorlueg.github.io/manifoldsR/reference/params_hierarchical.md).

## Usage

``` r
checkHierarchicalParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
