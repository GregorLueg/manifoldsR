# Check DREAMS params

Checkmate extension for the output of
[`params_dreams()`](https://gregorlueg.github.io/manifoldsR/reference/params_dreams.md).

## Usage

``` r
checkDreamsParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
