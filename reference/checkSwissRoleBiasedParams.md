# Check biased swiss roll params

Checkmate extension for the output of
[`params_swiss_role_biased()`](https://gregorlueg.github.io/manifoldsR/reference/params_swiss_role_biased.md).

## Usage

``` r
checkSwissRoleBiasedParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
