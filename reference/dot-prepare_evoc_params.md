# Internal helper to prepare EVoC parameters

Internal helper to prepare EVoC parameters

## Usage

``` r
.prepare_evoc_params(knn_method, nn_params, evoc_params)
```

## Arguments

- knn_method:

  String. Method for kNN graph generation.

- nn_params:

  Named list. Nearest neighbour search parameters.

- evoc_params:

  Named list. EVoC-specific parameters.

## Value

The merged list of final parameters.
