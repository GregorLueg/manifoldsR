# Get the kNN graph from an Evoc object

Get the kNN graph from an Evoc object

## Usage

``` r
get_nearest_neighbours(x)

# S3 method for class 'Evoc'
get_nearest_neighbours(x)
```

## Arguments

- x:

  An `Evoc` object.

## Value

A `NearestNeighbours` object, or `NULL` if the kNN was not stored.
