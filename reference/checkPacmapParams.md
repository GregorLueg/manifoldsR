# Check PaCMAP params

Checkmate extension for the output of
[`params_pacmap()`](https://gregorlueg.github.io/manifoldsR/reference/params_pacmap.md).

## Usage

``` r
checkPacmapParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
