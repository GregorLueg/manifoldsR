# Check swiss roll params

Checkmate extension for the output of
[`params_swiss_role()`](https://gregorlueg.github.io/manifoldsR/reference/params_swiss_role.md).

## Usage

``` r
checkSwissRoleParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
