# Check PHATE params

Checkmate extension for the output of
[`params_phate()`](https://gregorlueg.github.io/manifoldsR/reference/params_phate.md).

## Usage

``` r
checkPhateParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
