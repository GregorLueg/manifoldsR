# Check NCVis params

Checkmate extension for the output of
[`params_ncvis()`](https://gregorlueg.github.io/manifoldsR/reference/params_ncvis.md).

## Usage

``` r
checkNcvisParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
