# Check t-SNE params

Checkmate extension for the output of
[`params_tsne()`](https://gregorlueg.github.io/manifoldsR/reference/params_tsne.md).

## Usage

``` r
checkTsneParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
