# manifoldsR: Package for 2D embeddings

Contains different methods to generate embeddings like UMAP, tSNE,
PHATE, PacMap and diffusion maps. Morever, has methods to generate
nearest neighbour graphs and now also some clustering algorithms that
are based on embedding methods (EVoC) and more general clustering
methods like k-means.
