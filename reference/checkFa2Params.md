# Check ForceAtlas2 params

Checkmate extension for the output of
[`params_fa2()`](https://gregorlueg.github.io/manifoldsR/reference/params_fa2.md).

## Usage

``` r
checkFa2Params(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
