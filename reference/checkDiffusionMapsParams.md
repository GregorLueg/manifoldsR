# Check diffusion maps params

Checkmate extension for the output of
[`params_diffusion_maps()`](https://gregorlueg.github.io/manifoldsR/reference/params_diffusion_maps.md).

## Usage

``` r
checkDiffusionMapsParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
