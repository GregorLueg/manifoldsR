# Get the distances as a flat vector

Get the distances as a flat vector

## Usage

``` r
get_dist_flat(x)

# S3 method for class 'NearestNeighbours'
get_dist_flat(x)
```

## Arguments

- x:

  `NearestNeighbours` class

## Value

The distances in a flat format like
`c(dist1.1, dist1.2, ... , dist2.1, dist2.2, ... dist3.1, dist3.2)`
