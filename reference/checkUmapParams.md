# Check UMAP params

Checkmate extension for the output of
[`params_umap()`](https://gregorlueg.github.io/manifoldsR/reference/params_umap.md).

## Usage

``` r
checkUmapParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
