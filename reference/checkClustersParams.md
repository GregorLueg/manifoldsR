# Check cluster params

Checkmate extension for the output of
[`params_clusters()`](https://gregorlueg.github.io/manifoldsR/reference/params_clusters.md).

## Usage

``` r
checkClustersParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
