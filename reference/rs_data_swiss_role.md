# Generates the SwissRole data

**\[experimental\]** Generates synthetic data, i.e., the Swiss role to
test different manifold learning techniques

## Usage

``` r
rs_data_swiss_role(n_samples, noise, seed)
```

## Arguments

- n_samples:

  Integer. Number of data points to generate.

- noise:

  Numeric. How much noise to add.

- seed:

  Integer. For reproducibility purposes

## Value

The swiss role synthetic data with the desired parameters.
