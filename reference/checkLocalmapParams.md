# Check LocalMAP params

Checkmate extension for the output of
[`params_localmap()`](https://gregorlueg.github.io/manifoldsR/reference/params_localmap.md).

## Usage

``` r
checkLocalmapParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
